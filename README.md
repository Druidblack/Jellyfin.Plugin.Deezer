## Installation

Add `` https://raw.githubusercontent.com/Druidblack/Jellyfin.Plugin.Deezer/main/manifest.json `` in the plugin repository.

Supports:

* Automatic and manual matching is supported..
* Image and metadata for albums
* Images and metadata for performers.
